False positive report: HyperSense64.exe - detected as "Malicious"

HyperSense64.exe is a usermode memory-analysis GUI that embeds the open-source
Moneta scanner (GPLv3, https://github.com/forrest-orr/moneta). Reading another
process's memory is its documented function, not malicious behaviour: it uses
OpenProcess(PROCESS_VM_READ), VirtualQueryEx, PEB/TEB reads and SeDebugPrivilege
to map a target's regions and report suspicious memory (private executable
pages, modified code, unsigned modules).

credential access, no process injection, no code written outside the report the
user explicitly saves. The GUI starts asInvoker; elevation is opt-in via a
button. It is statically linked, not packed, and contains no obfuscated strings.
